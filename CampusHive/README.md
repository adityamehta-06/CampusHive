# CampusHive - Frontend

React frontend of CampusHive (campus resource sharing platform).

## Run

```
npm install
npm run dev
```

Opens on http://localhost:5173. The backend (`../server`) must be running on port 5000.

## Pages

- Home, Login, Register
- Resources (search + filters), Resource Details
- List Resource (with photo upload)
- Borrow Requests (owner), My Borrowed (borrower)
